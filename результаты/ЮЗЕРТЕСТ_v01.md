## Сценарий 1. Холодный старт — оценка 7/10

Шаги: открыл `/` → сразу режим «Простой старт», заголовок «Найдите узкое место потока», пустая таблица, кнопка «Демо: ОКЗ (комбикорм)» справа (скрин 01).

Что хорошо:
- Первый экран однозадачный, текст «Одна задача — один результат… Ничего не сохраняется и ни на что не влияет» — снимает страх «сломать».
- Демо-кнопка видна без прокрутки — новичку понятно, куда жать первой.

Затыки:
- Шапка «Рабочий инструмент РЦК-консультанта · маршрут проекта по улучшению (МУ-65)» — «МУ-65» новичку ничего не говорит, выглядит как шифр.
- В таблице уже подсвечены серые значения-плейсхолдеры (0,12 / 15 / 8400 / 0) — непонятно, это чужие данные или подсказка? Хочется их стереть, но неясно, надо ли.
- Колонки «ТЦ, МИН», «ВПП, СЕК» — аббревиатуры без расшифровки на экране. Знаки «?» рядом есть только у «ВПП итого» и «Такт», у колонок таблицы — нет.

## Сценарий 2. Демо ОКЗ — оценка 7/10

Шаги: «Демо: ОКЗ» → таблица заполнилась 11 операциями за ~1 с → тост «Отчёт обновлён — поиск узкого места» → отчёт далеко внизу, есть плавающая кнопка «↓ к отчёту» (скрины 02, 03).

Что хорошо:
- Скорость: кнопка → результат за 2 секунды, 1 клик. Это лучший момент продукта.
- «Главное узкое место» выделено крупно и по-человечески: «Процесс фасовки… — подтверждено 2 детекторами».
- Кнопка «↓ к отчёту» спасает — без неё отчёт под таблицей на 11 строк не нашёлся бы.

Затыки:
- «Масштаб: ВПП блока = 9,0 ч (32400 сек) = 38,7 % ВПП потока» — из контекста я догадываюсь, что это «доля времени, которое съедает эта операция», но слово «ВПП» нигде на экране не расшифровано. Что такое «38,7 % ВПП» — приходится угадывать. Новичок запомнит «38,7 %» и не сможет пересказать, процентов ЧЕГО это.
- «Тт: нет данных (домерить)» — «домерить» понятно, но что такое Тт — нет.
- Предупреждение «Разброс Тц 7,5×… детектор max(Тц) исключён из ранжирования» — написано для автора методики, не для инженера. «Кросс-детектор из четырёх независимых детекторов» — тоже.
- Список «Чего не хватает (домерить в первую очередь)» — хорошая идея, но пункты «спрос за период и доступное рабочее время → Тт» снова со стрелкой в непонятный термин.

## Сценарий 3. Свои данные из Excel + ошибки — оценка 5/10

Шаги: вкладка «Вставить из Excel» → вставил 4 строки табуляцией (одна строка с ПУСТОЙ ячейкой «производительность», одна с БУКВАМИ в «Тц») → «Разобрать в таблицу» → вкладка «Таблица» (скрины 04, 09, 10).

Что хорошо:
- Вкладка вставки имеет текст-подсказку про порядок колонок и «десятичная запятая допустима» — как раз для Excel-пользователя.
- Под таблицей появилась строка ошибки: «× строка 4 „Фасовка": не заполнено поле „Тц, мин"» — хоть какая-то обратная связь.
- У обязательной колонки есть «*» в заголовке и сноска «* — обязательно для расчёта».

Затыки (критичные):
1. **Буквы в числе молча исчезают.** Я ввёл «буквы» в Тц — поле показало серое «0,12» (плейсхолдер), а ошибка говорит «не заполнено поле». Но я-то ЗАПОЛНИЛ! Сообщение врёт о причине: должно быть «в поле не число». Доверие подорвано.
2. **Пустая ячейка молча превратилась в 15.** Строка 3 «Смешивание»: я оставил производительность пустой — в таблице появилось «15». Откуда 15? Это значение уйдёт в расчёт, а я его не вводил. Скрытая подстановка значений по умолчанию — опасно для «слепого» замера.
3. **Нет красной подсветки самой ячейки.** Ошибка — только текстовая строка под таблицей; строка 4 визуально ничем не отличается. При 11+ строках ищи сам, где «Фасовка».
4. **Отчёт просто исчез.** Пока в данных ошибка, область отчёта пустая — без сообщения «отчёт не построен, исправьте строку 4». Кажется, что программа «зависла».
5. Замечено ранее (п. 2, скрин 05): при пустом поле вставки «Разобрать» отвечает «Поле пустое — вставьте строки из Excel» — это правильно, но в тот момент таблица уже очистилась от демо-данных, а отчёт остался старым (рассинхрон: таблица пустая, отчёт про комбикорм).

## Сценарий 4. Полный режим + КПСЦ-карта — оценка 5/10

Шаги: «Полный режим» → линейка этапов «0 Предстарт … 5 Закрытие» → этап «2 Диагностика» уже открыт → «Демо: ОКЗ» → секция «Карта потока (КПСЦ)» ниже отчёта → «Построить карту» (скрины 11, 12, 13).

Что хорошо:
- Линейка этапов с подписями («карта текущего состояния, узкие места, потери») — единственное место, где видна логика всего продукта. Новичку это опорная карта.
- Подпись у кнопки: «данные берутся из таблицы „Поиска узкого места" — повторный ввод не нужен» — отлично, снимает главный вопрос.
- Итоги под картой: «ΣVA (ΣТц) = 78,1 сек · ΣNVA = 83709,3 сек… подсвечено УМ „Процесс фасовки…"» — связь с узким местом прослеживается.

Затыки:
1. **Кнопку «Построить карту» без подсказки не нашёл.** Она ниже длинного отчёта, в свёрнутой на вид секции «Карта потока (КПСЦ)». Название «КПСЦ» ничего не говорит; подзаголовок «SVG-карта потока из той же таблицы операций: ΣVA, ВПП и доля ценности на одном листе» — «SVG», «ΣVA» — язык разработчика.
2. **Карта нечитабельна.** Широкая SVG вписана в колонку ~766 px, текст внутри блоков микроскопический (скрин 13). Ни зума, ни «открыть во весь экран», ни клика-увеличения. Работать с картой на экране невозможно — только «Скачать .svg», а чем новичку открыть svg? (Ответ: браузером, но кто ему скажет?)
3. «Статус „С ПРОБЕЛАМИ" (домерить: запасы перед операциями; ВПП не по всем операциям; спрос/время → такт не вычисляется)» — полезно, но опять скобки в скобках и жаргон.
4. «Доля ценности = 0,1 %» — шок-цифра без объяснения «это норма для такого потока / это плохо». Новичок не знает, радоваться или паниковать.
5. **Демо-кнопка молча перезаписала мои данные.** Между сценариями 3 и 4 я нажал «Демо» — мои 4 строки исчезли без вопроса «заменить?». В простом режиме обещали «ничего не сохраняется», но уничтожение введённого — это тоже «влияет».

## ТОП-10 точек трения (по важности для новичка)

1. **Молчаливая подмена ввода:** буквы в числе → серый плейсхолдер + ложная ошибка «не заполнено»; пустая ячейка → значение «15» без спроса. Пользователь не контролирует, что ушло в расчёт. (сценарий 3)
2. **Нет красной подсветки ошибочной ячейки/строки** — ошибка только текстом под таблицей. (3)
3. **Жаргон без расшифровки в точке результата:** «38,7 % ВПП», «Тт», «ΣVA/ΣNVA», «КПСЦ», «детекторы» — главные цифры продукта невозможно пересказать своими словами. (2, 4)
4. **КПСЦ-карта нечитабельна на экране** — нет зума/полноэкранного режима, текст микроскопический. (4)
5. **Демо-кнопка уничтожает введённые данные без подтверждения.** (3→4)
6. **Кнопка «Построить карту» спрятана** ниже длинного отчёта под непонятным названием «КПСЦ». (4)
7. **При ошибке в данных отчёт исчезает молча** — нет заглушки «исправьте строку N, отчёт не построен»; возможен рассинхрон «таблица пустая — отчёт старый». (3)
8. **ЭЭ-калькулятор живёт не там, где его ищут** (этап 3 вместо «Закрытия»); ~25 полей с сокращениями без расшифровок. (5)
9. **Холодный старт не отвечает на «что я получу в итоге»** — нет одной фразы «вот ваш узкое место и сколько оно стоит» до нажатия демо; «МУ-65» в подзаголовке пугает. (1)
10. **«Доля ценности = 0,1 %» без интерпретации** — хорошо это или плохо, новичок не знает. Нужна подсказка-ориентир. (4)

## Поля, где нужна валидация «обязательно + красная подсветка» (звёздочки + красное — как просил пользователь)

Таблица «Поиск узкого места»:
- `Тц, мин` в каждой заполненной строке — уже есть «*», но нет красной подсветки при ошибке; ошибка «не число» должна отличаться от «не заполнено».
- `Операция` (название) — без него в отчёте строка безымянная; пометить «*» и подсвечивать пустое при заполненных числах строки.
- `ВПП итого, сек` (шапка) — без него «доля ВПП потока» не считается; сейчас молча выпадает в «пробелы».

ЭЭ-калькулятор (по осмотру): минимум `ee-предприятие`, `ee-поток`, `ee-тц-до`, `ee-тц-после`, `ee-цена` — нужны звёздочки + красная подсветка + блокировка расчёта до заполнения.

Протокол закрытия: 14 направлений «21 балла» — либо блокировать «Сформировать протокол» при «—», либо честно требовать «заполнено направлений: N из 14» красным до порога.
