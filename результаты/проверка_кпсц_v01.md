# Проверка генератора КПСЦ · vsm_karta.py v01

> Дата: 2026-08-04 · Роль: КПСЦ_Инженер_01 · Прогон: `данные_окз_слепой.json` (11 операций, ОКЗ)
> Артефакты: `карта_окз_v01.svg` (27 КБ), `карта_окз_v01.png`, `карта_окз_v01.html`

## 1. Что проверялось

1. Валидность SVG как XML — `xml.dom.minidom.parse` → **OK**.
2. Честность отображения: рисуется только то, что есть во входе; пробелы → статус «С ПРОБЕЛАМИ».
3. Читаемость на длинных именах ОКЗ (до 147 символов — «Процесс грануляции (накопительный бункер пресов → …)»).
4. Отсутствие наложений текстов — визуальная инспекция PNG (headless Edge, 3400 px).
5. Подсветка главного узкого места (фасовка, 2 детектора по протоколу № 12).
6. Линия времени VA/NVA и доля ценности — сверка с ручным расчётом.
7. Идемпотентность (два прогона → байт-в-байт) и прогон на `данные_умд.json`.

## 2. Архитектура layout

- Равномерная сетка: боксы 216 px, зазор 84 px (стрелка + место под треугольник запасов), поля 48 px. Ширина холста считается от числа операций — наложения невозможны по построению.
- Имя операции переносится по словам (≤ 30 символов в строке, ≤ 4 строк, дальше «…»). 30 симв. serif 9.5 px ≈ 145 px < 216 px — запас по ширине.
- Под именем — data-box (до 5 строк: Тц, ВПП, Пр, Возврат, Персонал; только имеющиеся поля, иначе «нет замеров»).
- Запасы: треугольник «I» между боксами **только** при честном `запас_перед_шт`; на ОКЗ запасов нет — треугольников нет (не выдумываем).
- Инфопоток сверху: Поставщик → Планирование → Клиент, пунктир от планирования к потоку (классическая нотация, данных о планировании нет — без цифр).
- Линия времени: нижние отрезки VA = Тц_i (сек), верхние зубцы NVA_i = ВПП_i − Тц_i; где ВПП нет — «?».
- Подсветка узкого места: терракотовая рамка 3 px + метка «★ УЗКОЕ МЕСТО».
- Палитра согласована с UI: терракота `#a4572f`, крем `#faf7f2`, тело `#333`.

## 4. Ограничения v01

1. Layout только горизонтальный, одна ветка — параллельные потоки/слияния не поддержаны (входа под них в спеке № 1 нет).
2. Зубцы линии времени фиксированной высоты (не масштабируются по величине) — масштаб 78 сек vs 32 400 сек визуально не выразить без логарифма; цифры честные, пропорции — нет.
3. Пиктограмма петли переделки («↺ брак») — только подпись, сама петля-стрелка к началу блока не рисуется.
4. Инфопоток декоративный (структура классики), данные о программе/заказах не вводятся.
5. Конвертация в PNG внешняя (в проверке — headless Edge); ядро само только SVG/HTML.
6. Имя узкого места должно совпадать с `операции[].имя` точно (строка-в-строку); при несовпадении подсветки нет, карта строится.

## 5. Как воспроизвести

```bash
cd ИИ-направление/Прототип
python3 vsm_karta.py данные_окз_слепой.json \
  -o результаты/карта_окз_v01.svg \
  --html результаты/карта_окз_v01.html \
  --glavnoe "Процесс фасовки на одном выбойном аппарате (фасовка в мешок 30 кг)"
```
