## 2. Закрытые миноры

1. **Валидация `фонд_времени`:** если объект присутствует, все три значения
   (смены, часы, дни) обязаны быть числами > 0, иначе отказ с указанием секции и поля.
   Тесты: `{"смены":-2,…}` → отказ «секция «фонд_времени», поле «смены»: должно быть
   числом больше 0»; ноль, не-число, неполный объект — тоже отказ; валидная тройка —
   проходит. Зафиксировано в спеке, п. 5.1а.
2. **`спрос_превышает_возможности`:** выбран путь валидации (не вычёркивания).
   Предупреждение при противоречии флага связке Тцикл/Ттакт состояния «до»
   (флаг «да», но Тцикл < Ттакт — и наоборот). Не отказ: флаг остаётся декларативным,
   расчёт объёма идёт по связке, как в модели. Зафиксировано в спеке, п. 5.1б.
   Ни один из 4 регрессионных кейсов предупреждение не вызывает.
3. **Косметика:**
   - «−0,00» в контрольной сверке нормализовано в `rub()`: |x| < полкопейки → +0;
   - docstring `ui/app.py` обновлён: «Прогон 3», два инструмента
     (Поиск узкого места + ЭЭ-калькулятор);
   - `loadEE` (index.html) больше не отбрасывает нулевые значения полей;
   - подпись «Прочий эффект … (реальный, если отмечено: ☐)» → «если флажок установлен».
