Структура карточки проекта (подтверждена образцом + 2 заполненными экземплярами):
гриф «УТВЕРЖДАЮ / директор / подпись / дата» → заголовок «Проект по оптимизации: «…»» →

идеальный), **Вовлечённые лица и рамки проекта** (клиенты, периметр, границы, владелец,
руководитель проекта, команда).

## 3. Ограничения v0.1

1. Приложения № 1–3 к приказу (состав рабочих групп, перечень курсов, план ключевых
   задач) не генерируются — только тело приказа и карточка.
2. Оригинальные карточки — «4 картинки»-блока с произвольной вёрсткой; генерат
   воспроизводит структуру и содержание, но не пиксельную вёрстку (плоские блоки docx).
3. Рамка ПТ проверяется только для показателя «выработка» (единственный, к которому
   рамка применима по смыслу); идеальное состояние нормативом не валидируется.
4. Справочник МУ-66 покрывает 4 показателя (выработка, трудоёмкость, ВПП, запасы);
   прочие — честный флаг «локальный показатель, методику указать вручную».
5. В архиве нет заполненного приказа именно Гидропресса — реквизиты приказа в тесте
   условные; форма приказа взята из официального шаблона прил. № 2.
6. Дельта-режим (`sravnit`) для протокола закрытия: предложен формат итогов
   (`цели[*].дельта_пкт`, `флаги`), сама функция сравнения — задел волны 3.
