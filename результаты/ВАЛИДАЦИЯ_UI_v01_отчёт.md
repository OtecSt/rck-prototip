Изменены только `templates/index.html` и `static/style.css`. Бэкапы: `*.bak_val01`. Мосты `__acUM/__acEE/__acData/__pzSkelet`, id, API-контракты, localStorage-ключи, стек — не тронуты. БД: дамп до = дамп после (тестовые прогоны не создавались). Сервер остановлен.

## По пунктам объёма

**1. Валидация таблицы операций (карточка УМ)** — сделано.
- Буквы/мусор: ячейка подсвечивается красным (рамка + фон, класс `.bad`), расчёт не уходит, сообщение конкретное: «строка 3 «Процесс фасовки…», колонка «Тц, мин»: введено «абв» — нужно число» (скрин 02).
- Пустая обязательная ячейка (Тц или название операции в частично заполненной строке): мягкая янтарная подсветка (новый класс `.miss`) + сообщение «строка N: не заполнено поле «Тц, мин» — обязательно для расчёта» / «не заполнено название операции» (скрин 03). Расчёт блокируется.
- «Не число» и «не заполнено» различаются и цветом, и текстом.
- Молчаливая «15» устранена: это был плейсхолдер-число в пустом поле (сервер никогда не подменял — подтверждено курл-тестом №4). Плейсхолдеры заменены на «напр. 0,12 / напр. 15 / напр. 8400 / напр. 0» — пустое поле теперь явно пустое, в расчёт уходит только введённое пользователем.
- Звёздочки: у «Тц, мин» была, добавлена у «Операция» (сервер её тоже требует — поведение приведено к звёздочкам).

**2. Валидация ЭЭ-калькулятора** — сделано (скрин 05).
- Обязательные: предприятие, поток, Тцикл до/после, Ттакт до/после, время до/после, цена, переменная с/с. У предприятия и потока добавлены звёздочки.
- При попытке расчёта (живой пересчёт) пустые обязательные подсвечиваются янтарём, статус перечисляет: «Не заполнены обязательные поля (подсвечены): Поток, Тцикл до, …». Фокус переходит на первое незаполненное — но не отбирается, пока пользователь печатает в форме. Свежая пустая форма не «кричит» (подсветка только после первого ввода в карточке).

**3. Демо-confirm** — сделано (скрин 04). Если в таблице/полях есть введённые данные, «Демо: ОКЗ» спрашивает «Заменить введённые данные демо-примером «ОКЗ»?»; при отмене данные остаются (проверено: confirm вызван, строка «МОЯ ОПЕРАЦИЯ» не заменена).

**4. Плашка «отчёт устарел»** — сделано в обеих карточках (УМ и ЭЭ). При ошибке/нехватке данных старый отчёт не исчезает молча: остаётся приглушённым (opacity .45) под янтарной плашкой «Отчёт устарел — исправьте подсвеченные данные, отчёт пересчитается автоматически» (скрины 02, 03). Если отчёта ещё не было — зона скрыта, как раньше. После успешного пересчёта плашка снимается.

**5. Расшифровки жаргона у цифр результата** — сделано.
- У плашки «Главное узкое место» под строкой масштаба: «ВПП — время протекания продукции: столько времени продукт стоит и ждёт, а не обрабатывается. Процент — какая доля этого ожидания приходится на узкое место. ВПП — типично 60–95 % всего времени потока, цель проекта — его снизить» (видно на скрине 04).
- У итогов КПСЦ: «Доля ценности — отношение времени ценности к ВПП: только X % времени продукт реально обрабатывается»; при < 1 % добавляется «Почти всё время — ожидание: для дискретного производства это норма и главное поле для улучшений». Формулировки сверены с методичкой (ВПП — полное время производственного цикла; доля ценности — отношение времени ценности к ВПП, МЕТОДИЧКА_пользователя.md, п. 5.4).
- Тц/Тт: «?»-подсказки у колонок «Тц, мин» и «ВПП, сек» таблицы (title + data-tip), у поля «Тцикл узкого места до» в ЭЭ; у «Тнеобх.такт» подсказка уже была.

**6. Кнопка «Построить карту»** — сделано (скрин 06). Кнопка переведена из второстепенного стиля в основной (терракота, `.btn`), добавлен стиль `:disabled`; описание карточки заменено на человеческое: «Карта потока из той же таблицы операций выше: видно, где продукт обрабатывается, а где стоит и ждёт… просто нажмите «Построить карту»». Карточка не перестраивалась.

## Ручные сценарии (headless Edge, драйвер через временную iframe-страницу, удалена)

- Буква «абв» в Тц строки 3 → красная ячейка, расчёт не ушёл, сообщение с именем строки и введённым значением; старый отчёт под плашкой «устарел» (скрин 02).
- Стертые Тц и название → янтарь + «не заполнено», расчёт не ушёл (скрин 03).
