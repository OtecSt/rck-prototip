## ВЕРДИКТ по шкале Agentik: **CRITICAL_STOP**

Три независимых способа получить ЛЖИВЫЙ или МЁРТВЫЙ сервис:

1. **Подписной протокол с 42 баллами из мусора.** Чек-лист принимает оценку
   «АБРАКАДАБРА» как соответствие — 87 мусорных оценок → 42/21 балла,
   «порог пройден», docx на подпись. Ноль предупреждений (У-2).
2. **NaN-отравление убивает проект.** Один прогон с `NaN` сохраняется в
   immutable-снапшот и навсегда ломает JSON всей истории проекта для браузера
   (У-1). Валидация чисел слепа к NaN/Infinity во ВСЕХ инструментах.
3. **Подписной ЭЭ = «nan руб/год» / «inf руб/год»** — ядро ЭЭ честно печатает
   nan/inf в отчёт и в итоги вместо отказа (У-3).

Плюс блокер эксплуатации: удаление/повреждение файла БД = молчаливая смерть
всех API с 500-HTML, сервер сам создаёт пустую БД-заглушку и продолжает
«работать» (У-4). До PASS систему не выпускать.

- **Отрицательный ЭЭ в отчёте калькулятора** — показан честно: «Реальный ЭЭ: −204 161 234,47 руб», сверка факторов сходится (позорище только в протоколе, У-9).
- **Immutable-доктрина**: отчёт/итоги от клиента действительно не принимаются — сервер пересчитывает ядром (проверено кодом и поведением).
