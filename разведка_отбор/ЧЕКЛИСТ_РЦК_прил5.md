# Чек-лист очного отбора предприятия в проект (РЦК) — Приложение № 5
## МР-15-2026 «Отбор предприятий для участия в федеральном проекте "Производительность труда"», редакция № 5 от 28.07.2026

Источник: дословная выпись из PDF (Приложение № 5, стр. 25–29 PDF; извлечено pypdf). В колонтитулах страниц ошибочно указано «редакция № 4» — содержательно это ред.5 (технический дефект самой методички, см. РАЗБОР_МР_отбор_ред5.md, п. «Примечание»).

**Порог (п. 3.7 МР):** «1. При сумме баллов 18 и более, а также при отсутствии отсекающих критериев – рекомендовать предприятие для реализации проекта при поддержке ФЦК / РЦК. 2. При выявлении на предприятии ограничений, связанных с отсекающими критериями, и / или сумме баллов менее 18 не рекомендовать предприятие для реализации проекта». Каждый пункт = 1 балл.

**Легенда:** `V` соответствует критерию; `─` не соответствует критерию; `*` отсекающий критерий; `+` есть дополнительные сведения на обороте чек-листа.

**Важно (дословно из МР):** «Чек-лист заполняется исключительно экспертами ФЦК / РЦК и не подлежит заполнению руководителем / сотрудниками предприятия. Оценочные листы, заполненные иными лицами, к рассмотрению не принимаются». Чек-лист подписывается руководителем предприятия и участниками процесса очного отбора.

## Раздел 2. В момент реализации проекта на предприятии не планируется структурных изменений (1 пункт, пометка «+»)

Отметка о соответствии критерию ставится при условии отрицательного ответа на вопросы — планируется ли в ближайшие 3 – 6 месяцев:

- смена генерального директора;
- смена кого-либо из заместителей генерального директора;
- смена инвестора или собственника;
- переезд на новую площадку;
- запуск / строительство нового цеха.

«В случае положительного ответа на один из выше указанных вопросов, указать плановую дату завершения структурных / системных изменений» (пометка `+` — доп. сведения на обороте).

## Раздел 3. Для предприятий ОПК / выпускающих продукцию двойного назначения: (1 пункт, отсекающий *)

- предприятие готово предоставлять полную бухгалтерскую и налоговую отчетность в соответствии с соглашением (по всему предприятию, без выделения гражданской части из общей выручки и других финансовых показателей);
- на предприятии отсутствует пересечение потоков гражданской и военной продукции (отсутствуют риски остановки процесса производства гражданской продукции, для выполнения срочных ГОЗ);
- отсутствуют ограничения, связанные как с доступом сотрудников РЦК на производственные участки / цеха, в периметре которых планируется оптимизировать пилотный поток (проект) так и с требованиями по наличию формы допуска к информации, составляющей государственную тайну.

## Раздел 4. (1 пункт, отсекающий *)

«Предприятие подтверждает, что продукция предлагаемого для оптимизации потока производится и реализуется на оборудовании и производственных площадях данного юридического лица» *

## Раздел 5. Оценка потенциала производства (4 пункта; 5.4 — условно отсекающий)

| № | Критерий (дословно) | Отсекающий |
|---|---|---|
| 5.1 | Предлагаемый для оптимизации продукт / услуга / поток (для реализации пилотного проекта) занимает значительную долю в выручке предприятия (не менее 10 %) | |
| 5.2 | Предлагаемый для оптимизации продукт / услуга / поток имеет потенциал роста продаж, увеличение выработки востребовано | |
| 5.3 | Предприятие подтверждает базовую загрузку / базовые объемы продаж производственных мощностей (например, путем предоставления подписанных договоров с клиентами, бизнес-планов, планов производства, планов по предоставлению услуг на 1 / 2 / 3 года и т.п.) | |
| 5.4 | Предприятие подтверждает самостоятельность в сбытовой политике, в том числе в управлении ценообразованием, производством и себестоимостью | при отрицательном ответе критерий **может являться отсекающим** |

*Примечание: в шапке раздела 5 чек-листа (лицевая сторона 2-го листа) фиксируется «Наименование потока, выбранного для реализации пилотного проекта» — поле без балла.*

## Раздел 6. Производство имеет потенциал быстрых улучшений: (16 пунктов)

| № | Критерий (дословно) |
|---|---|
| 6.1 | Цикл производства / товарооборота / предоставление услуги (время полного изготовления / предоставления продукта / время полного оборота товаропотока / услуги) не превышает 1 месяц |
| 6.2 | Присутствует достаточное количество неавтоматизированных рабочих мест (есть заметный потенциал повышения производительности неавтоматизированных операций) |
| 6.3 | Сотрудники предприятия признают наличие проблем, связанных с простоями оборудования / рабочими центрами (переналадки, обслуживание, ППР, аварийные ремонты) |
| 6.4 | Сотрудники предприятия признают наличие проблем, связанных с качеством продукции / оказания услуг |
| 6.5 | В производстве имеются избыточные запасы между операциями и на складах |
| 6.6 | В производстве имеются избыточные документы / транзакции между подразделениями / внутри подразделений |
| 6.7 | Передача изделий между операциями производится необоснованно большими партиями с применением специальных средств |
| 6.8 | Передача информации между операциями производится необоснованно большим объёмом (как в бумажном виде, так и с применением CRM систем) |
| 6.9 | В производстве имеются пересечения между продуктами / потоками, есть избыточная транспортировка из-за неоптимальной расстановки оборудования / расположения мест хранения / расположения рабочих центров |
| 6.10 | В производстве имеются пересечения с другими услугами, есть проблемы в кросс-функциональном взаимодействии подразделений |
| 6.11 | Неэффективная организация рабочих мест: захламленность, отсутствие стандарта содержания и другие признаки |
| 6.12 | Низкий уровень культуры безопасности: сотрудники не носят СИЗ, на полу нет разметки и другие признаки, не соблюдаются отраслевые нормы и правила |
| 6.13 | В цехах / структурных подразделениях компании отсутствуют информационные центры, либо их содержание не актуально (устарело, не обновляется) |
| 6.14 | Визуально заметны незанятые, простаивающие сотрудники |
| 6.15 | Сотрудники по-разному выполняют одну и ту же работу / операцию |
| 6.16 | Собственная развитая система по внедрению инструментов «Бережливого производства» отсутствует |

## Оборотная сторона 1 листа (команда проекта, к п. 1.3)

- Генеральный директор — 1; Заместитель генерального директора* — >=2; Эксперты** — >=5; Рабочая группа — >=3.
- `*` по производству, по финансам, по персоналу; `**` начальники цехов, руководитель отдела по качеству, начальник технического отдела и др.
- Загрузка: рабочая группа — от 1 до 3 часов в день; эксперты — 70–100 % рабочего времени. Встречи: 1 раз в неделю / 2 раза в неделю / по необходимости для решения и обсуждения проблем, гипотез, предложений.
