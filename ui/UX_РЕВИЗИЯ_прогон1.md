# UX-ревизия «Агент-цех», прогон 1 (28.07.2026)

**Метод:** ролевое приёмочное тестирование (две роли: инженер РЦК с листом ПА; директор по производству).
Полный текст находок — в сводке агента UX_Ревизор_Ролевой_01 (ниже — структурированная выжимка).

## Вердикты
- Роль 1 (инженер РЦК): ГОДЕН К РАБОТЕ с доработками.
- Роль 2 (директор): ДОРАБОТАТЬ — «где узкое место» видно за 5 секунд, «насколько плохо» и «что домерить» — нет.

## Находки (приоритет)
1. [БЛОКЕР/Р2] Нет масштаба потерь в понятных единицах у главного УМ (сек → часы/смены). Правка: в плашку «Главное» строку масштаба («ВПП блока = 9,0 ч/сут = 38,7 % потерь потока»).
2. [ВАЖНО/Р1] Такт/спрос/доступное время не вводятся через UI — детектор «Тц > Тт» и дисбаланс 5 % недоступны. Правка: 3 необязательных поля в meta-grid.
3. [ВАЖНО/Р1] Нечисловой мусор в ячейке молча отбрасывается; ошибка указывает не на ту причину. Правка: подсветка ячейки + сообщение «не число».
4. [ВАЖНО/обе] Ничья «2 детектора = 2 детектора» неявна; эшелон 2 ВПП приравнен к эшелону 1; «главный резерв времени» может оказаться у не-главного УМ. Правки: взвесить детекторы/показать ничью; смягчить формулировку до «крупный резерв времени».
5. [ВАЖНО/Р2] «Домерить» спрятан в разделе 6 — дублировать топ-3 в верхнюю плашку.
6. [ЖЕЛАТЕЛЬНО] Легенда «* — обязательно»; заголовок Excel только в первой строке; сек→ч двойной записью в разделе 4; расшифровка аббревиатур; ellipsis для длинных имён операций.

## Грамматика/формулировки (править)
1. «7. Показанные расчёты» → «7. Расчёты (как считали)»
2. «считает то, на что хватает входа» → «считает по тем данным, которые введены»
3. «6. Домерить» → «6. Каких данных не хватает (что домерить)»
4. Звёздочка без легенды
5. «Поиск узкого места» vs «Поиск узких мест» — унифицировать
6. «Ядро: узкие_места.py v0.3» в футере → «Ядро расчёта v0.3»
7. «кандидат на темп потока» → «кандидат на роль темпа потока»
8. «Демо: ОКЗ» — расшифровать/переименовать кнопку
9. «СТАТУС ОТЧЁТА: С ПРОБЕЛАМИ (домерить: 2)» → «Статус: есть пробелы в данных (2 пункта)»
10. «маршрут проекта по улучшению» → «маршрут проекта улучшений» (проверить по МУ-65)
